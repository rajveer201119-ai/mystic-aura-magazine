# Mystic Aura Magazine

A responsive fashion and lifestyle magazine website for Mystic Aura, built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Editorial home page
- Previous editions with year filtering
- Team page
- Contact page with frontend validation
- Newsletter validation
- Responsive luxury magazine styling
- SEO metadata for primary pages

## Development

```bash
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm.cmd run build
```
